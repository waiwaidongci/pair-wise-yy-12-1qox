# hxyfront-62011 马术蹄铁修整档案 · 四蹄测量适配与蹄铁领用台

源提示词编号：6

在原有修蹄记录（马匹列表、复查提醒、左右前后蹄对比、异常步态标记、蹄铁更换历史）之上，扩展为面向蹄铁师的**四蹄测量适配与蹄铁领用台**。

## 业务规则（红线均集中在 `src/domain/rules.ts`）

1. **一马一单**：每匹马仅允许一张未结束适配单（测量中 / 待备料 / 待试装复核）。
2. **缺项不得启动**：四蹄的蹄长、蹄宽、钉孔距、全部钉位，以及步态分级、装蹄蹄铁师、下次复查日期缺一不可。
3. **整单备料闸口**：任一蹄出现
   - 蹄长 / 蹄宽 / 钉孔距与库存蹄铁相差 **超过 2 毫米**，或
   - **钉孔模式不符**，或
   - **钉位落入蹄底敏感区**（距蹄踵 < 20 毫米），

   则整单停在「待备料」，**库存不扣减**；四蹄全部通过后才扣库进入试装。
4. **双人双次确认**：试装后须由**另一名蹄铁师**（不同于装蹄人）**连续两次**确认「步态稳定 + 蹄铁无松动」才完成；任一次不通过即清零连续计数。
5. **结论失效**：修正测量、更换蹄铁、停用库存都会使试装/复核结论失效。
   - 进行中单：清空试装与确认，重新校验；换铁按「旧铁退库 +1、新铁扣库 -1」处理。
   - 已完成单：走「修正后重新适配」——旧单归档只读留档，新单沿用已领蹄铁（台账标记 `reused`），**不重复扣库**，并重新走试装 + 双人双次确认。
   - 停用库存：占用该蹄铁的进行中适配单退回待备料，库存数量不变。

## 分层结构

```
src/
├── domain/            # 规则层：纯函数，不依赖 React / localStorage
│   ├── types.ts       # 领域模型（适配单、四蹄测量、钉位、库存蹄铁、台账…）
│   ├── rules.ts       # 缺项校验、2mm/模式/敏感区判定、备料计划、双确认、提醒与指标
│   └── seed.ts        # 演示种子数据
├── persistence/
│   └── repository.ts  # 持久化层：localStorage 读写 + 跨标签页 storage 同步
├── state/
│   └── store.ts       # 状态层：所有变更的唯一入口，库存增减只在此落账
└── ui/                # 界面层：列表、四蹄卡片、详情弹层、库存、提醒、档案
```

列表、库存、提醒均由同一份数据经选择器派生（`buildMetrics / buildReminders / evaluateOrder`），任意操作提交后各视图刷新一致；跨标签页通过 `storage` 事件同步。

## 界面

- **适配工作台**：指标卡 + 适配单列表（状态/步态/复查筛选）+ 复查提醒 + 规则速览
- **适配单详情**：四蹄长宽/钉孔距/钉孔模式/钉位录入（敏感区实时高亮）、库存蹄铁推荐与选配、左右前后蹄对比表、阶段动作、双人双次确认面板、蹄铁领用台账（issued / reused）、操作时间线
- **蹄铁库存**：SKU 台账、入库、新增、停用/启用（停用影响进行中单）
- **完成与归档档案**：已完成单与失效留档旧单（只读，可在新/旧单之间跳转）

数据保存在浏览器 localStorage（键名 `hxyfront-62011:fitting-data:v1`），页头「重置演示数据」可恢复种子。
